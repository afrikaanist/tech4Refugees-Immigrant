# Tech4RIM website

Public website for Tech4RIM: technology with refugees, immigrants and migrants.

## Publishing

The website is built with plain HTML, CSS and JavaScript and is intended for GitHub Pages. Participant records, contact lists, consent forms, banking details and other private data must never be committed to this public repository.

## Updating content

- Main pages: `index.html`, `about.html`, `programs.html`, `impact.html`, `contact.html`
- Design: `style.css`
- Mobile navigation and email form: `site.js`
- Search discovery: `robots.txt` and `sitemap.xml`

The public name is Tech4RIM. Tech4RIM is the public-facing name of Tech4Refugees & Immigrants.
